{% note warning %}

**Пока не реализовано.** Маршруты ниже смонтированы на порту 9090, но каждый из них возвращает
`501 Not Implemented`; отвечает только `/-/ready`. Эта страница описывает *планируемую*
поверхность, чтобы интеграторы видели направление, — пока не стройте на ней интеграции.

Для запросов к метрикам сегодня используйте [Arrow Flight SQL](../guides/querying.md) поверх тех же
данных.

{% endnote %}
