# Централизованное Логирование для Микросервисов

{% note warning %}

Эта страница находится в процессе перевода. Полную документацию см. в [английской версии](../../en/cookbooks/centralized-logging.md).

{% endnote %}

Этот cookbook описывает настройку централизованного логирования для архитектуры микросервисов с использованием OpenTelemetry Collector в качестве агента сбора и {{product_name}} в качестве бэкенда хранения. Вы узнаете, как настроить пайплайны сбора, маршрутизацию логов и визуализацию в Grafana.
