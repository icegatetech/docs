# Распределённая Трассировка

{% note warning %}

Эта страница находится в процессе перевода. Полную документацию см. в [английской версии](../../en/cookbooks/traces-end-to-end.md).

{% endnote %}

Этот cookbook описывает, как инструментировать сервисы с помощью OpenTelemetry SDK, отправлять трейсы в {{product_name}} через OTLP и запрашивать их через Tempo API (порт 3200). Вы узнаете, как настроить пропагацию контекста и визуализировать трейсы в Grafana.
